# PenBird

PenBird is a multipurpose WordPress theme for blogs, business sites, and shops. It runs on its own, with layouts and colors set in the Customizer. Elementor and X Addons for Elementor are optional.

Theme page: https://pencilwp.com/product/penbird

## Description

PenBird gives you a masonry post grid, a custom header and footer, and styled WooCommerce shop, cart, and product pages. Page templates can use a boxed or full-width container, and posts can sit with a left sidebar, a right sidebar, or no sidebar. Header and footer colors, logo size, typography, and copyright text are all theme options. The theme does not require a page builder.

## Features

- Masonry blog grid with featured images, excerpts, and sticky-post styling
- Header layouts with logo placement, menu alignment, search, and an optional sticky header
- WooCommerce cart icon in the header when WooCommerce is active
- Footer widget areas, footer alignment, and an editable copyright line
- Customizer colors, Inter typography, container width, and content width
- Breadcrumbs on pages, archives, and search
- Per-page layout controls for the container, sidebar, header, footer, title, and breadcrumb
- Custom logo, custom header image, custom background, and a primary menu
- Threaded comments and translation-ready strings (`penbird`)

## Optional plugins

These are suggested only. The theme still works if they are not installed.

- [Elementor](https://wordpress.org/plugins/elementor/)
- [X Addons for Elementor](https://wordpress.org/plugins/x-addons-elementor/)
- [WooCommerce](https://wordpress.org/plugins/woocommerce/)

## Requirements

- WordPress 7.0 or newer
- PHP 8.3 or newer
- Tested up to WordPress 7.1

## Installation

1. In the WordPress admin, go to **Appearance → Themes → Add New**.
2. Click **Upload Theme** and choose the PenBird zip file.
3. Click **Install Now**, then **Activate**.
4. Open **Appearance → Customize** to set the logo, header, footer, colors, and layout.
